# Colaboração (três integrantes ativos, dois com possível apoio)

1. Criar uma branch por frente (`feat/ingestion`, `feat/pipeline`, `feat/api-web`).
2. Fazer commits pequenos e com mensagens objetivas; enviar branch ao GitHub.
3. Abrir PR com issues relacionadas, como testar e evidências reais.
4. Não compartilhar senhas reais, tokens, keytabs ou `.env` no Git.
5. Acordar o contrato em `docs/SCHEMA.md` antes de integrar componentes.
6. Em caso de mudanças no contrato, discutir no PR; não mudar campos sozinho.
7. Não alterar a `main` com código não revisado.
8. Cada participante deve saber explicar sua própria contribuição.

O auxílio de IA deve ser registrado no relatório, conforme o enunciado.
